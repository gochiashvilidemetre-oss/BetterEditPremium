# Better Edit Premium

Better Edit Premium is a planned collection of Geometry Dash editor workflow tools.

The current source is an initial development scaffold. No advertised editor
feature should be considered implemented until it has been coded, compiled,
and tested in-game.

Planned tools include same-type selection, trigger group visualization, object
search and labels, improved object-page navigation, and saved copy organization.
Any AI feature intended for the Geode Index will be limited to transparent,
advice-only assistance in accordance with current Geode guidelines.
